# Versões de firmware

Algumas funcionalidades descritas nesta documentação estão disponíveis apenas em versões específicas de firmware dos equipamentos **iDFace** e **iDFace Max**. Quando uma página mencionar **V6**, **V7** ou **V8**, use o número de série do equipamento para identificar qual versão de firmware ele utiliza:

| Firmware | Linha do equipamento | Números de série começando com |
| --- | --- | --- |
| **V6** | iDFace | 0M01, 0M02, 0M03 ou 0M04 |
| **V7** | iDFace Max | 0X01, 0X02, 0X03 ou 0X04 |
| **V8** | iDFace | 0M05, 0M06, 0M07 ou 0M08 |
| **V8** | iDFace Max | 0X05, 0X06, 0X07 ou 0X08 |

Nota

O firmware **V8** é o mesmo para os equipamentos iDFace e iDFace Max. Por isso, ele abrange as duas faixas de números de série acima.
