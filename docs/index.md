# ControlId.Net

Biblioteca .NET para equipamentos Control iD: controle de acesso (iDAccess, iDFlex, iDBlock e similares) e REP iDClass
(Portaria 671), com cliente HTTP, parser de AFD, integração com injeção de dependência e ASP.NET Core (Monitor, Push e modo online).

## Por onde começar

- [Guia](guia.md): instalação e uso.
- [Cobertura](COBERTURA.md): o que da API dos equipamentos já está implementado.
- [Decisões de arquitetura](adr/README.md): o porquê das escolhas.
- [Referência da API](xref:ControlId.Net): gerada a partir do código (`ControlId.Net`, `ControlId.Net.DependencyInjection`, `ControlId.Net.AspNetCore`).
